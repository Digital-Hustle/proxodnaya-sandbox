# ADR-041 · Выдача ролей и вид терминала

## Доступ к панели
- Новый раздел «Доступ» (`/admin/access`). Он виден только администратору (право `access`).
- Администратор может:
  - пригласить человека (имя, рабочая почта, роль);
  - сменить роль;
  - отключить доступ или вернуть его.
- Статусы: «приглашён» → «активен» после первого входа, «отключён».
- Защита, которую проверяет сервер (`mock/server.ts`), а не только интерфейс:
  - менять доступ может только активный администратор;
  - свою роль сменить и себя отключить нельзя;
  - последнего активного администратора нельзя понизить или отключить;
  - почта уникальна и проверяется на корректность.
- Каждое действие пишется в журнал доступа (`accessLog`, только дописывается): кто, кому, что, когда.
- Сессия хранит пользователя, а роль берётся из его учётной записи:
  - когда роль меняют, панель сразу перестраивается;
  - когда доступ отключают, человек выходит из панели.
- Переключатель «Роль» заменён на «Сменить пользователя». Это демо-вход: в продукте вход идёт по корпоративной учётной записи.
- При ручной проверке прохода в журнал записывается имя проверяющего.
- Миграция аддитивная: для старых данных `admins` берутся из seed, а `accessLog` начинается пустым.

## Терминал без рамки
- Экраны киоска больше не рисуют карточку и своё сияние.
- Весь экран лежит на общем фоне приложения с ровным затемнением (`bg-background/30`), поэтому киоск выглядит частью того же продукта, что и главная, пропуск и панель.
- Своё окно со скруглением осталось только у видео с камеры.

## Анимации
- Смена QR у рабочего идёт по очереди, без наложения: старый код растворяется в расфокус, новый фокусируется.
- Камера и фон сменяются симметрично:
  - с одной и той же длительностью и кривой;
  - с размытием;
  - уход камеры начинается с короткой паузой.
  CSS-переход у видео убран (ADR-036).
- Сканер «Покажите QR»: возвращён прежний вид — тонкий градиентный луч между уголками. Добавлено только мягкое свечение, цикл туда-обратно бесшовный.
  Везде не больше двух ключевых кадров.
