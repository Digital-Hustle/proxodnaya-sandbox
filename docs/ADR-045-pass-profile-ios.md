# ADR-045. Карточка пропуска v3.3, профиль, морф QR, фиксы iOS

Статус: принято · Связано: ADR-043, ADR-044

## Контекст
- На карточке пропуска QR заходил на зелёную шапку, имя дублировалось в заголовке экрана и в карточке, «Мои объекты» перегружали главный экран.
- У сотрудника не было профиля и способа отвязать телефон.
- Смена QR раз в 30 с была резкой подменой картинки.
- iOS Safari: полоса «Обновится через…» периодически рисовалась поверх скругления/рвалась; шапка дрожала при прокрутке.
- Сканер киоска: хотелось больше характера в анимации ожидания.

## Решение
1. **Пропуск.** Заголовок экрана — «Пропуск». Зелёная врезка `bg-brand-deep p-4` внутри карточки, только аватар/ФИО/должность/теги; тег «N объекта» ведёт в профиль. QR ниже отдельно. Хелпер карточки — `pages/worker/lib/card.ts` (`useWorkerCard`, `forgetWorkerCard`).
2. **Профиль** `/worker/profile` — 4-я вкладка: допуск до, «Мои объекты», «Этот телефон» (устройство, дата ключа, установка PWA), оформление, «Выйти с этого телефона». Выход: `api.revokeDevice` → удаление ключа `phone` из IndexedDB → очистка кэша карточки → `/worker/activate`. Вернуться можно только по новому коду приглашения.
3. **Морф QR.** `shared/lib/qrShape` разделён на `qrMatrix` / `bodyPath` / `dotPath` / `finderPaths` (`qrShape` сохранён). `StyledQr morph` ведёт путь тела через ref: общие модули стоят, исчезающие сжимаются, новые вырастают с перелётом, волна от центра (~1 с). React во время анимации путь не трогает; в конце ставится точный путь нового кода, так что сканируемость не зависит от анимации. `prefers-reduced-motion` — мгновенная замена. Пути точек пишутся компактно (3 знака, относительные команды).
4. **CountdownBar.** Причина артефакта: `scaleX` у заливки внутри `overflow-hidden rounded-full` + перезапуск пружины каждые 250 мс. WebKit при масштабировании слоя внутри скруглённого клипа периодически теряет маску. Теперь — `translateX` заливки полной ширины, одна линейная анимация на всё окно (`ease.linear`, новый токен), дорожка `isolate transform-gpu overflow-hidden`.
5. **Шапка iOS.** `min-h-dvh` → `min-h-svh` в оболочках (киоск остаётся `h-dvh`), фон `Aurora` — `fixed inset-x-0 top-0 h-lvh` вместо `inset-0`, `HeaderBar` — `transform-gpu`. Гипотеза: при скрытии адресной строки `dvh` и холст фона меняли размер каждый кадр → перерасчёт раскладки и дрожание шапки. Проверяется только на устройстве.
6. **ScanMark.** После выгиба линии в «U» появляются глаза, моргают, затем кольцо замыкается, глаза уходят — дальше прежний цикл (галочка → крестик → точка).

## Последствия
- Новый токен `ease.linear` (сгенерировано в theme.css / DESIGN.md).
- Полосы обратного отсчёта — только через `CountdownBar`.
- Выбор темы: подпись «Системная», иконки скрыты до `sm`, чтобы подписи не обрезались на телефоне.
